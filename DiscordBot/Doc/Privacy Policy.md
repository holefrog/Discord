# Privacy Policy (隐私政策)

*Last updated: November 2026*

This Privacy Policy explains how **Bot-Muse** ("the Bot"), a personal Discord bot project, handles user data.

---

### 1. Data Collection (数据收集)
- **No Personal Data Collected:** The Bot does **not** collect, store, log, or sell any personal information (such as real names, emails, IP addresses, or payment details).
- **Transient Processing:** When the Bot is mentioned or invoked, message content and context are processed in-memory solely to generate the reply and are discarded immediately after.

### 2. Data Usage & Storage (数据使用与存储)
- We do not maintain any persistent database of chat messages or user profiles.
- Any local runtime cache (e.g., message IDs to prevent duplicate replies) is temporary, contains no personal information, and is used strictly for basic bot operations.

### 3. Third-Party Services (第三方服务)
The Bot runs on the Discord platform and may use upstream AI API providers to generate responses. Use of Discord is subject to the [Discord Privacy Policy](https://discord.com/privacy).

### 4. Data Deletion & Contact (数据删除与联系方式)
Because the Bot does not store personal data or message history, there is no retained user data to delete. If you have any questions or concerns, please contact the bot owner directly on Discord or open an issue on the project repository.
